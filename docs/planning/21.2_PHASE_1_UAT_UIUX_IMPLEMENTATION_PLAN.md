# Hoàn Thiện UI/UX & UAT — World Cup 2026 (MVP Production)

## Bối cảnh

Backend MVP **đã hoàn tất** (v0.1 → v1.0.0, 60/60 tests PASS). Hiện **chỉ có Admin Panel Filament**, chưa có **Player UI**. Cần xây dựng Player UI + hoàn thiện Admin Panel + chạy UAT nội bộ. WC2026 đang diễn ra (12/06/2026).

## Confirmed Decisions

| # | Câu hỏi | Quyết định |
|---|---------|-----------|
| 1 | Architecture | **Filament dual-panel** (Admin `/admin` + Player `/player`) |
| 2 | Branding | Tên web/app: **"World Cup 2026"**, có logo riêng, admin có thể sửa trong Settings |
| 3 | Dữ liệu WC2026 | CSV sẵn có: `docs/operation/import_samples/fixtures_import_full_wc2026.csv` (105 trận) |
| 4 | UAT testers | Admin tự thêm user qua Filament Admin Panel |
| 5 | Deploy | **Local development** trước, dùng `filament-local-logins` plugin để test nhiều account trên 1 browser. Setting cho phép bật/tắt plugin này |

## Design Decisions

| Quyết định | Lý do |
|---|---|
| Filament dual-panel | Tốc độ nhanh nhất, tái sử dụng auth/layout/widget, WC2026 đang diễn ra |
| Player panel path `/player` | Tách biệt hoàn toàn với admin `/admin` |
| Dùng Filament Pages cho Player | Player không cần CRUD, chỉ cần view + action đặt bet |
| `filament-local-logins` cho UAT | Quick-switch accounts trên local, bật/tắt qua Settings |
| `spatie/laravel-settings` cho App Settings | Admin tự chỉnh branding, stake limits, feature flags |
| Branding "World Cup 2026" configurable | Admin sửa qua Settings, không hardcode |
| Wording tiếng Việt: "dự đoán", "lá" | Tuân thủ legal compliance |
| CSV import 105 trận WC2026 | File sẵn có, dùng `import:wc2026` command đã build ở v0.11.0 |

## Verification Plan

### Automated Tests

```bash
# Existing tests không broken
php artisan test   # → 60/60 PASS

# New tests (thêm)
php artisan test --filter PlayerPanelTest       # Auth guard, redirect, rules acceptance
php artisan test --filter PlaceBetFlowTest      # E2E bet placement
php artisan test --filter AdminResourceTest     # User/Season/Bet CRUD
php artisan test --filter SettlementFlowTest    # Settlement preview/execute via admin
```

### Manual UAT (local via `filament-local-logins`)

1. `php artisan db:seed --class=StagingSeeder`
2. `php artisan serve`
3. Mở `/admin` → login admin → tạo markets → publish
4. Mở `/player` → dùng local-logins switch giữa 5 players → đặt bets
5. Quay lại admin → nhập kết quả → preview → execute settlement
6. Check player wallet, bets status, leaderboard

### Security

- Player **cannot** access `/admin`
- Player **cannot** see other users' bets/wallet
- `filament-local-logins` **disabled** ngoài env `local`
